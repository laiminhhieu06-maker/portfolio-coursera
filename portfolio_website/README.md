# My Portfolio — Web Design Capstone (Option 1)

This is a sample portfolio coded from scratch with HTML, CSS, and JavaScript. It is not a commissioned client site. Customize the wording, project examples, and contact information so the website genuinely represents your work.

## Open locally
1. Extract the zip file.
2. Double-click `index.html` to open it in Chrome or Edge.
3. Edit files using VS Code. No external libraries, installation, or internet access required.

## Files
- `index.html`: semantic HTML5 content and website sections.
- `styles.css`: CSS variables, typography, grid, Flexbox, styling, and responsive media queries.
- `script.js`: interactive features.
- `desktop_preview.png` and `mobile_preview.png`: preview screenshots generated locally.
- `submission_description.txt`: example English project explanation.

## At least four enhancements
1. Accessible mobile menu: open and close on small screens.
2. Dark/light theme toggle, remembers your choice if browser storage is available.
3. Filterable project cards (All / Business / Creative).
4. Floating back-to-top button when scrolling down.
5. Native expandable FAQ sections.

Additional details: keyboard skip link, visible focus states, semantic sections and headings, reduced-motion preference, image descriptions, CSS Grid/Flexbox, and mobile media queries.

## Before submitting on Coursera
- Change the name and profile text to your own information.
- Replace the practice concepts with projects you actually built or clearly keep the practice labels.
- Replace `your-email@example.com` with your own contact address (or remove the email button).
- Open the site locally and test it on mobile and desktop screen widths.
- Validate your actual HTML with https://validator.w3.org/nu/ (File Upload or Text Input). Fix any reported errors. Do not claim to have passed validation until you run it.
- For the course submission, include a short description, screenshots demonstrating mobile and desktop, and optionally a hosted website URL (e.g. GitHub Pages) or short video if the assignment form requests it.
- Follow Coursera's academic integrity and AI policies. Review and adapt the sample before making a declaration that it is your own work.

## Publish on GitHub Pages (optional)
Create a public GitHub repository, upload the site files to the repository root, then go to Settings > Pages > Build and deployment > Deploy from a branch > main / root. Once GitHub Pages publishes, copy the live URL into the Coursera URL field.
