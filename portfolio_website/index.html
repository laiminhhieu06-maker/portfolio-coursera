Was this website coded from scratch?

Yes. The demonstration uses original HTML, CSS, and JavaScript files, without a site builder, CSS framework, or external package.

Does the layout work on mobile?

Yes. Flexible CSS layouts and media queries adapt the navigation, grids, and text spacing to smaller screens.

What is the purpose of this portfolio?

It demonstrates foundational web design skills and serves as a starting point that can be customized with genuine student projects.
